<h1>Thought Dumper </h1>
<hr>
A simple and lightweight thought saving website that helps  you to email yourself any thought, idea, reminder or file instantly from any device without login and no login nothing required.
<hr>
<h3>Features:</h3>
<ol>
    <li>Email yourself any thought or idea instantly</li>
    <li>Attach Multiple images, videos or pdf files too</li>
    <li>Files get uploaded to cloud and sent as a link</li>
    <li>Minimal and clean interface nothing extra</li>
    <li>No login signups no barriers to use </li>
</ol>
<hr>
<h3>How it Works :</h3>
<p>Just open the website and : </p>
<ol>
    <li>Type your email address</li>
    <li>Write down whatever is on your mind</li>
    <li>Attach a file if you want</li>
    <li>Hit send and it lands straight into your inbox</li>
</ol>
